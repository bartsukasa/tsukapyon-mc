サーバーに参加するには
ホワイトリスト登録が必要です

Tsukapyon MC はホワイトリスト制のサーバーです。登録なしではアドレスを知っていても接続できません。
Discord で /register コマンドを使うだけで登録できます。3ステップで完了！

① Minecraft ID を確認
→
② Discord に参加
→
③ /register を送信
→
✅ 参加OK！
1
Minecraft ID を確認する
Minecraftランチャーの右上に表示されています

Minecraft ID（Minecraft ユーザー名） とは、Minecraft上で他のプレイヤーから見える名前のことです。ランチャーを開いて右上のアカウント欄で確認できます。

💡 ランチャーが見つからない場合 スタートメニューで「Minecraft Launcher」を検索してください。インストールしていない場合は minecraft.net からダウンロードできます。
⚠️ 大文字・小文字に注意！ Minecraft IDは大文字・小文字を区別します。Steve と steve は別の名前です。ランチャーで確認した名前をそのままコピーしてください。
2
Discord サーバーに参加する
まだ参加していない場合のみ

すでに Tsukapyon MC の Discord サーバーに入っている場合はこのステップは不要です。下のボタンから参加してください。

Tsukapyon MC Discord に参加する
💡 参加後にすること Discord に入ったら、まず自己紹介・ルール確認チャンネルを確認してください。ロール（Lv0）が付与されるとサーバーへの参加が可能になります。
3
/register コマンドを送信する
Discord の任意のチャンネルで送れます

Discord のチャットに /register と入力するとコマンドが出てきます。minecraft_id の欄に Step 1 で確認した Minecraft ID を入力して送信してください。

メッセージを送信、または /register と入力
↑ このような画面になります。返信は自分にしか見えません（ephemeral）
💡 コマンドの使い方 ① チャットに /register と入力する
→ コマンド候補が出るので「register」を選択
② minecraft_id の入力欄に自分の Minecraft ID を入力
→ 例：Steve（大文字・小文字そのまま）
③ Enter で送信
→ Bot から「ホワイトリストに追加しました」と返信が来ればOK！
✅
Bot から「追加しました」と返ってきたら登録完了！
Lv0 以上のロールが付いていれば、すぐにサーバーに接続できます。
ロールがまだない場合は管理者（つかぴょん）に声をかけてください。
😢 うまくいかないときは？
「ホワイトリストに登録されていません」と言われる → まだ Lv0 ロールが付いていない可能性があります。Discord で管理者に声をかけてください。
Minecraft ID を間違えた → もう一度 /register 正しいID を送ると上書き更新されます。
Bot が反応しない → Bot がオフラインの可能性があります。しばらく待ってから再試行してください。
