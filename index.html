Forge をインストールする
バージョンは必ず 1.20.1–47.4.10（違うと接続不可）

「Forge」はMinecraftにMODを追加するための土台です。バージョンが1文字でも違うとサーバーに接続できません。かならず以下のボタンから直接ダウンロードしてください。

⚠️ ダブルクリックしてもメモ帳で開かれる場合 Java がインストールされていません。Forge のインストーラー（.jar ファイル）を実行するには Java が必要です。

① 下のボタンから Java をダウンロード・インストールする
→ Eclipse Temurin（Java 21）をダウンロード
Windows x64 の .msi を選んでインストールしてください。

② インストール後、PC を再起動する
再起動しないと Java がシステムに認識されません。必ず再起動してください。

③ 再起動後、Forge インストーラーをダブルクリック
今度は「アプリを選択して .jar ファイルを開く」が出ず、Forge の画面が起動します。

① インストーラーをダウンロード

Forgeインストーラー（バージョン固定リンク）
forge-1.20.1-47.4.10-installer.jar（5.8 MB）

ダウンロード先：https://adoptium.net/temurin/releases/?version=21
「Windows x64 .msi」を選んでインストールすれば解決します。

② .jar ファイルをダブルクリックして起動
ダウンロードした forge-1.20.1-47.4.10-installer.jar をダブルクリックするとインストーラーが開きます。

4
MOD を全部インストールする
mods.zip をダウンロードして解凍します

サーバーで使っている71個のMODを、まとめてダウンロードして設置します。

① mods.zip をダウンロード

MODセット一括ダウンロード
mods.zip（約103 MB・71個入り）

② mods.zip を解凍する
ダウンロードした mods.zip を右クリックして「すべて展開...」を選択。
解凍先はどこでも大丈夫です（デスクトップなど）。解凍するとフォルダが作られ、中に .jar ファイルが71個入っています。

❌ zip のまま入れても動きません mods.zip を直接 mods フォルダに入れてもMODは読み込まれません。必ず解凍してから .jar ファイルをコピーしてください。

③ modsフォルダを開く
キーボードの Windowsキー + R を同時に押して「ファイル名を指定して実行」を開き、以下をコピペしてEnterキーを押してください。

「ファイル名を指定して実行」に入力してEnter
%AppData%\.minecraft\mods
ファイル名を指定して実行
名前(O):
💡 mods フォルダが存在しない場合 .minecraft フォルダの中に mods フォルダがなければ、新規作成してください。
フォルダ内で右クリック →「新規作成」→「フォルダー」→ フォルダ名を mods にすればOKです。

④ .jar ファイルをすべてコピー
解凍してできたフォルダを開き、中の .jar ファイルをすべて選択（Ctrl + A）して、開いた modsフォルダにドラッグ＆ドロップします。

❌ よくあるミス — フォルダごとコピーしない 解凍後にできるフォルダをそのまま mods フォルダに入れてもMODは読み込まれません。フォルダの中にある .jar ファイルをコピーしてください。
✓
確認： modsフォルダを開いて .jar ファイルが70個以上 並んでいればOK！

Forgeプロファイルで起動する
「forge-1.20.1」を選ぶのがポイント

Forgeをインストールすると、Minecraft Launcherに「forge-1.20.1」という新しいプロファイルが追加されます。このプロファイルで起動しないとMODが動きません。

① Minecraft Launcher を開く
Launcherを開くと、画面の左下にプロファイル（起動構成）の選択欄があります。

Minecraft Launcher
左下のプロファイル欄

▼
▶ PLAY

② プロファイルを「forge-1.20.1」に切り替えて PLAY
プロファイル欄の ▼ をクリックして一覧を開き、forge-1.20.1 を選択してから PLAY ボタンを押してください。
初回起動時はMODの読み込みに 2〜5分ほど かかることがあります。黒い画面のまましばらく待ってください。

💡 メモリ割り当てを増やすと快適に 71個のMODは重いため、4GB以上のメモリ割り当てを推奨します。
Launcher → 起動構成 → forge-1.20.1 の鉛筆アイコン → 「詳細設定」→「JVM引数」の
-Xmx2G の部分を -Xmx4G（または -Xmx6G）に変更してください。

③ タイトル画面に「Mods」ボタンが表示されることを確認

「Mods」ボタンをクリックするとインストール済みのMOD一覧が確認できます。71 mods loaded と表示されていれば完璧です！

❌「Mods」ボタンが出ない場合 プロファイルが forge-1.20.1 ではなく 1.20.1（バニラ）や Latest release になっています。
左下のプロファイル欄をもう一度確認して forge-1.20.1 に切り替えてください。
❌ 起動中にクラッシュする場合 modsフォルダに不要なファイルが混入している可能性があります。
クライアント不要のMOD（Chunk-Pregenerator・spark・ftb-backupsなど）が入っていたら削除してください。

FAQ
よくある質問
クリックすると答えが開きます！
「Mods」ボタンが表示されない
＋
Minecraft LauncherのプロファイルがForgeになっていない可能性があります。Launcherを開いて左下のプロファイル欄が 「forge-1.20.1」 になっているか確認してください。「Latest release」や「1.20.1」（バニラ）になっている場合は切り替えてから起動してください。
「MODが一致しません」エラーが出る
＋
クライアント側のMODとサーバー側のMODが異なっています。mods.zipを再ダウンロードして、modsフォルダを一旦空にしてから入れ直してください。古いバージョンのMODが残っていると発生します。
「バージョンが違います」と言われる
＋
Forgeのバージョンが 47.4.10 でない可能性があります。Launcherのプロファイルでバージョンを確認してください。違う場合はStep2からやり直してください。
サーバーに繋がらない（タイムアウト）
＋
① サーバーが停止中：Discordの #bot チャンネルでサーバー状況を確認してください。定期再起動中（0・4・8・12・16・20時）は一時的に繋がりません。
② アドレスの入力ミス：tsukapyon.playit.plus を正確に入力してください。
「Chunk Pregenerator has failed to load」エラー
＋
Chunk PregeneratorはサーバーのみのMODで、クライアントには不要です。modsフォルダから Chunk-Pregenerator-1.20-4.5.3.jar を削除してから起動してください。最新のmods.zipをダウンロードし直すと解決します。
「FerriteCore がインストールされていません」警告
＋
警告なので 「メインメニューへ戻る」 を押せばそのまま遊べます。最新の mods.zip には FerriteCore が含まれているので、再ダウンロードすれば消えます。
家具（テーブル・チェア）が作れない
＋
Valhelsia Furniture MODを 1.1.3 以上に更新する必要があります。最新の mods.zip には 1.1.3 が含まれているので再ダウンロードしてください。
レシピはどうやって調べる？
＋
JEI（Just Enough Items）が入っているので、インベントリ右側にアイテム一覧が表示されます。アイテムにカーソルを合わせて Rキー で作り方、Uキー で使い道が確認できます。MOD名で絞り込むには検索欄に @valhelsia のように入力してください。
死んだときアイテムはどこへ？
＋
Gravestone MODが入っているため、死亡した場所に 墓石 が設置されてアイテムが収納されます。墓石に近づいて右クリックすると全回収できます。焦らなくて大丈夫！
ゲームが重い・カクつく場合は？
＋
① Launcherのインストール → 鉛筆アイコン → 詳細設定 → JVM引数の -Xmx を -Xmx4G 以上に変更
② 映像設定でレンダー距離を8チャンク以下に
③ OptiFineは競合する可能性があるため非推奨です。
黄昏の森への行き方は？
＋
2×2の池を掘って水を入れ、周囲を花で囲み、池の中に ダイヤモンド を投げ入れると雷が落ちてポータルが開きます！
