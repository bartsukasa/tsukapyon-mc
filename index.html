公式サイト

2
Forge をインストールする
バージョンは必ず 1.20.1–47.4.10（バージョン違いは接続不可）

MODを動かすためのソフト「Forge」をインストールします。バージョンが1文字でも違うと接続できないので、必ず以下のリンクを使ってください。

① インストーラーをダウンロード
forge-1.20.1-47.4.10-installer.jar（5.8 MB）

② ダウンロードした .jar ファイルをダブルクリックして開き、下の画面が出たら 「Install client」 を選んで OK をクリック。

Forge Installer
インストール先を選んでください
❌ よくあるミス Forge の公式サイトにある「Recommended」ボタンや「Latest」ボタンを押すと別バージョンがインストールされます。必ず上記のリンクから 47.4.10 を直接ダウンロードしてください。
💡 Java がない場合 Forge のインストーラーを開いたとき「Javaが見つかりません」というエラーが出た場合は、Java 21（Temurin）をここからインストールしてから再試行してください。
✓
確認：「Successfully installed client profile forge for version 1.20.1-47.4.10」と表示されたらインストール完了です。
3
MOD を全部インストールする
下のリンクから mods.zip をダウンロードします
① まず mods.zip をダウンロードする
https://github.com/bartsukasa/tsukapyon-mc/releases/download/v1.0/mods.zip

② mods フォルダを開く

キーボードの Windowsキー と R を同時押しすると「ファイル名を指定して実行」が開きます。以下をコピーして貼り付け、Enterを押してください。

「ファイル名を指定して実行」に貼り付ける
%AppData%\.minecraft\mods
ファイル名を指定して実行
名前(O):
%AppData%\.minecraft\mods

② mods.zip を解凍する

管理者からもらった mods.zip を右クリック →「すべて展開」（または「解凍」）します。

③ .jar ファイルを mods フォルダにコピーする

解凍してできたフォルダの中にある すべての .jar ファイル を、先ほど開いた mods フォルダにドラッグ＆ドロップしてコピーします。

❌ よくあるミス zip ファイルのまま入れないこと。必ず解凍（展開）してから、中の .jar ファイルを入れてください。

また、一部のファイルだけ入れても動きません。全ファイルが必要です（60個以上あります）。
✓
確認： mods フォルダを開いて、.jar ファイルが60個以上入っていることを確認してください。

サーバーアドレス

つながらない場合
以下を順番に確認してください
Mods ボタンが出ない
Launcher のプロファイルが「forge-1.20.1」になっているか確認。バニラで起動していませんか？
接続エラーが出る
mods フォルダに .jar が60個以上入っているか確認。zip のまま入れていませんか？
バージョン違いエラー
Forge のバージョンが 47.4.10 かどうか確認。Launcher のプロファイル名を見てください。
サーバーが見つからない
管理者にサーバーが起動中か確認してください。起動していないと接続できません。
